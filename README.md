# FortressSaga Tool

《洛伊的移動要塞》機械工程 5×5 配置編輯與優化工具。

## 功能

- 5×5 拖曳配置
- 上下左右同類連接檢查
- 2～7 顆連接加乘
- 增幅零件品質範圍（非傳說 1 格、傳說 2 格）
- 同款增幅零件可重複放置，各自品質獨立
- 左、右、上、下、水平、垂直、十字與全方位方向檢查
- 28 顆普通零件 0 階～滿階區間，階數（只由增幅器提供）等距內插後再乘連接倍率
- 超過最大階數的增幅會標示為浪費
- 攻擊、防禦、輔助、弱化與均衡配置優化（先修復成合法配置，再最佳化）
- 優化重點可選增幅階數優先（預設）／數值總分／連接數優先
- JSON 配置匯入與匯出
- 離線執行，不需安裝
- 36張ICON為128×128透明WebP正方形，只保留原始物件，不疊加黃框、箭頭或濾鏡
- 手機版底部零件側欄：點空格選零件、分類篩選、已用零件變灰、長按拖曳交換

## 使用方式

下載後雙擊 `index.html` 或 Windows 上的 `啟動工具.bat`。

## 測試

```bash
node --test connectivity.test.js effect-engine.test.js icon-assets.test.js mobile-ui.test.js
```
